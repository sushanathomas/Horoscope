# Horoscope App

A responsive horoscope app built with HTML, CSS, and JavaScript.
Enter your birthday to discover your zodiac sign and read its horoscope message.

<img width="673" height="369" alt="Horoscope" src="https://github.com/user-attachments/assets/3b6e2c5d-e92f-438c-86aa-9db80c6acf2c" />


## Features

- Identifies all 12 zodiac signs using your birthday.
- Displays a horoscope message for each sign.
- Prompts you to enter a birthday if the input is empty.
- Adapts to desktop, tablet, and mobile screens.

## Technologies

- HTML
- CSS
- JavaScript

## Run Locally

Download or clone this repository, then open index.html in your browser.
No installation or build process is required.

## How It Works

JavaScript handles the form submission, reads the birthday's month and day,
and displays the matching zodiac sign and message.

The messages are predefined and do not automatically change each day.
